# Design System Guidelines

Global UI / UX tokens and standards for projects.

## Core Rules

1. **Tokens Over Hardcoded Values**: Never use raw hex/color constants directly in components.
2. **Typography**: Define standard scale (display, heading, body, caption).
3. **Spacing**: 4px/8px incremental grid scale (4, 8, 12, 16, 24, 32, 48, 64).
4. **Dark Mode First-Class**: Every token must map to corresponding light and dark theme semantics.
5. **Component Reusability**: Extract buttons, headers, cards, pills into shared component libraries.
